今天的项目：Research / Data Analyst Agent

五、先自己回答一个重要问题
写代码之前，在 notebook 里写一段 Markdown：

## Agent vs deterministic responsibilities

### LLM
- Understand the user's question
- Decide which tool to call
- Decide tool arguments
- Decide whether more research is needed
- Synthesize evidence
- Produce final analyst conclusion

### Code
- Retrieve numerical data
- Perform calculations
- Validate inputs
- Execute tools
- Enforce tool-call limits
这一段 非常重要。

因为如果以后面试官问：

Why did you build this as an agent?

你就不会只说：

Because I used LangGraph.

而会说：

I used deterministic code for numerical retrieval and calculations, while the LLM handled ambiguous decisions such as selecting tools, determining whether additional research was needed, and synthesizing evidence.

这才是 AI Engineer 的回答。

七、创建 tools
这里开始真正 coding。

结构建议：

import pandas as pd

df = pd.read_csv("macro_data.csv")
然后：

from langchain_core.tools import tool
例如：

@tool
def get_country_data(country: str, year: int) -> dict:
    """Get macroeconomic indicators for a country and year."""

    result = df[
        (df["country"] == country)
        & (df["year"] == year)
    ]

    if result.empty:
        return {
            "error": f"No data found for {country} in {year}"
        }

    return result.iloc[0].to_dict()
注意 docstring。

你已经学过：

Tool schema 是给 LLM 看 tool capability 的重要信息。

所以不要：

"""get data"""
而应该明确：

"""Retrieve macroeconomic indicators including GDP growth,
inflation, unemployment, and debt-to-GDP for a specific
country and year.
"""

九、创建 Agent Node
Agent node 非常简单：

    response = llm_with_tools.invoke(

    return {
        "messages": [response]

对。

十一、创建最核心的 Graph
from langgraph.graph import StateGraph, START, END
from langgraph.prebuilt import tools_condition
然后：

builder = StateGraph(State)

builder.add_node(
    "analyst",
    analyst_agent
)

builder.add_node(
    "tools",
    tool_node
)
edges：

builder.add_edge(
    START,
    "analyst"
)
最关键：

builder.add_conditional_edges(
    "analyst",
    tools_condition
)
然后：

builder.add_edge(
    "tools",
    "analyst"
)
最后：

graph = builder.compile()
你现在得到了：

START
  ↓
analyst
  ↓
Does AIMessage contain tool_calls?
  │
  ├── yes → tools
  │            ↓
  │        analyst
  │            ↓
  │          ...
  │
  └── no → END
这就是今天项目最重要的一张图。

十四、加入 System Prompt
然后提高 analyst quality：

SYSTEM_PROMPT = """
You are a research and data analyst.

Your job is to answer analytical questions using available tools.

Rules:

1. Use data tools for quantitative claims.
2. Never invent numerical values.
3. Use calculation tools instead of doing arithmetic mentally.
4. Use web search when external explanations or recent context are required.
5. Distinguish facts from interpretation.
6. Do not repeatedly call tools if sufficient evidence already exists.

这里同时复习：

prompt 是 agent architecture 的一部分。

为什么这样划分
LangChain 当前官方文档也把 LangChain agents 定位为更方便的高层实现，而当你需要更细粒度的执行流、state 和 routing 控制时，可以直接使用 LangGraph primitives。所以今天坚持自己用 StateGraph + ToolNode + conditional edges 搭，而不是直接调用一个现成 agent abstraction，是非常适合你当前学习阶段的。

你现在第一步就做 macro_data.csv + 4 个 tools。先不要碰 LangGraph。 等四个 tools 都能独立运行，再把它们接入 graph；这样你会清楚地区分 Tool → Tool Calling → Agent Loop → LangGraph orchestration，而不会把所有概念混在一起。
